Loan Prediction Web App

A simple machine learning project that predicts whether a loan will be approved based on user inputs.
This project uses a RandomForest Classifier, a Flask backend, and a modern UI for easy interaction.

Features

Predicts loan approval using ML

Clean and easy-to-use web interface

Trained on real loan dataset (614 records)

Encodes categorical inputs automatically

Fast and lightweight Flask app

Technologies Used

Python

Flask

Scikit-Learn

Pandas, NumPy

HTML & CSS (Frontend)
